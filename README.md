# Web Informasi Sekolah 🏫

Sistem informasi profil sekolah modern yang dibangun menggunakan **Laravel 11**, **Filament PHP v3** untuk panel admin, dan **Supabase PostgreSQL** sebagai databasenya.

## ✨ Fitur Utama
* **Halaman Publik Terspesialisasi**: Menampilkan Profil Sekolah, Direktori Guru, Berita/Artikel, dan Daftar Ekstrakurikuler.
* **Layanan Kontak**: Formulir hubungi kami yang terintegrasi langsung ke dashboard admin.
* **Admin Dashboard (Filament)**: Panel admin yang cantik dan responsif untuk mengelola seluruh konten web (CRUD).
* **Database Supabase**: Menggunakan PostgreSQL dari Supabase untuk performa dan skalabilitas tinggi.

## 🚀 Teknologi yang Digunakan
* [Laravel 11](https://laravel.com)
* [Filament v3](https://filamentphp.com)
* [Supabase](https://supabase.com) (PostgreSQL)
* Tailwind CSS
